# テストコード

採用した実装を確かめる自動テストと、固定のテスト入力を置きます。現在はテスト基盤未定で、実行可能なテストはありません。

- [機能仕様](../docs/features/README.md)の受入条件を根拠にします。
- テスト名やコメント、または機能の `verification.md` で、受入条件IDとテストの対応を示します。
- 実行結果・対象の版・未実施理由は機能の `verification.md` に記録します。テストコードの存在だけで成功とは扱いません。
- 実際のテストコマンドは [ルートREADME](../README.md) へ記載します。

技術選定後に単体・結合・画面操作など必要な区分を作ります。コードの隣へテストを置く構成を選ぶ場合は [整頓ルール](../docs/guide/file-organization.md)を更新します。
