## 画面

| 要素 | 表示・操作 |
| --- | --- |
| 入力欄 | ラベル「タスク名」。追加失敗時には内容を保持する |
| 追加ボタン | 入力を検証して追加する。成功時に入力欄とエラー表示を空にする |
| エラー表示 | 入力欄に対応づけて、失敗理由を文字で示す |
| タスク一覧 | 追加順。各行にタスク名と完了チェックボックスを置く |
| 空の状態 | 0件のときだけ「タスクはありません」を表示する |
| 保存の説明 | 常に「再読み込みするとタスクは消えます」と表示する |

## データ

| データ | 内容・制約 |
| --- | --- |
| タスク一覧 | メモリ上の配列。画面の初期化時に空配列にする |
| タスクの識別子 | 画面内で重複しない値。同名のタスクを区別するために使う |
| タスク名 | 前後の空白を除いた1〜100文字の文字列 |
| 完了状態 | 未完了または完了。追加時は未完了 |
| 入力・エラー | 画面のメモリで保持する。外部には保存しない |

## 処理

1. 追加操作で、入力の前後の空白（全角空白を含む）を除く。
2. Unicodeコードポイントで文字数を数える。0文字なら入力必須、101文字以上なら上限超過のエラーを表示して終了する。
3. 有効なら新しい識別子と未完了状態を付け、一覧の末尾へ追加する。同名の照合による拒否は行わない。
4. 追加成功時に入力欄とエラーを空にする。失敗時は一覧と入力内容を保持する。
5. 完了操作は識別子で対象を特定し、その1件の完了状態を反転する。
6. 再読み込みでは新しい空の一覧から開始する。保存・復元する処理は設けない。
