# 廃止文書一覧

現在の作業の根拠として使わなくなった文書を置きます。完了した機能でも、今使われる仕様なら [features](../features/README.md) に残します。

元のカテゴリとIDを保ち、例えば `docs/features/FEAT-001-task-list/` を `docs/archive/features/FEAT-001-task-list/` へ移します。文書冒頭に `状態: 廃止`、廃止理由、後継のリンクを記載します。後継がない場合はその理由を明示してください。

| 文書ID | 旧パス | 移動後の文書 | 廃止理由・日付 | 後継 |
| --- | --- | --- | --- | --- |

現在、廃止文書はありません。

移動時は文書内部と参照元の相対リンクを修正します。現役文書の依存先は後継へ切り替えるか、必要な内容を現役側へ移します。詳細は[整頓ルール](../guide/file-organization.md)を参照してください。
