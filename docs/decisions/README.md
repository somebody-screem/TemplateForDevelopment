# 決定記録一覧

「なぜこの方法を選んだか」を残す場所です。ADR（Architecture Decision Record）は、背景・選択肢・決定・影響を短く記録する文書です。重要な技術選定や、後で再検討しそうな判断に使います。

[原本](../../templates/decision.md)を `ADR-NNN-short-name.md` にコピーし、以下の一覧へ登録します。

| 決定ID | 決めたことへのリンク | 後継の決定 |
| --- | --- | --- |

現在、決定記録はありません。小さな実装の工夫は機能設計の中で説明できます。

依存先には判断の根拠となる要件・機能仕様を記載します。決定を反映する全体設計・機能設計は「関連資料」に記載します。設計側がその決定に依存する場合、逆向きの依存を作らないようにしてください。

決定を覆す場合は、旧記録の内容を新しい結論で書き換えず、新しいIDの記録を作ります。旧記録は廃止にし、理由と後継を示して[廃止文書一覧](../archive/README.md)へ登録します。
