# 機能一覧

1機能につき `FEAT-NNN-short-name/` を作り、機能仕様・設計・作業計画・検証記録をまとめます。[機能テンプレート](../../templates/README.md)をフォルダ単位でコピーしてください。

| 機能ID | 日本語の機能名 | 仕様 | 設計 | 作業 | 検証 |
| --- | --- | --- | --- | --- | --- |

現在、実プロジェクトの機能は未登録です。[記入例](../../examples/README.md)は別フォルダにあります。行を追加するときは各文書への相対リンクを記載します。設計・作業を仕様へ統合した場合は「仕様内へ統合」と明記してその節を案内します。

| ファイル | 書くこと | 依存先 |
| --- | --- | --- |
| `spec.md` | 目的・要件・受入条件 | 全体要件 |
| `design.md` | 構成・データ・失敗時の扱い | 機能仕様・全体設計 |
| `tasks.md` | 実装手順と完了条件 | 機能仕様・機能設計 |
| `verification.md` | 条件とテストの対応・実行結果 | 機能仕様・作業計画 |

仕様の状態は各文書の冒頭、実装の進捗は作業計画、検証の成否は検証記録を見ます。完了した機能も利用されている間はここに残します。
