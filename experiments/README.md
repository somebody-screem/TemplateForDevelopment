# 試作一覧

アイデアを動かして確認するコードと、その結果を保存します。1つの問いにつき `EXP-NNN-short-name/` を作り、[試作メモの原本](../templates/experiment.md)をその中の `README.md` にコピーします。

| 試作ID | 試す問い・メモへのリンク | 採用先の機能仕様 |
| --- | --- | --- |

現在、試作は未登録です。個別フォルダにはメモ、再現できるコード、必要な小さな入力例をまとめます。メモに実行方法と結果を記載し、生成物や共有不要のログは `.tmp/` へ置きます。

採用時には、振る舞いを `docs/features/` の仕様へ書き、必要なコードを `src/`、テストを `tests/` へ整理します。元のメモには採用先をリンクします。破棄する場合も結果と理由を残せば同じ調査を繰り返さずに済みます。

進め方は[開発手順](../docs/guide/workflow.md)、配置は[整頓ルール](../docs/guide/file-organization.md)を参照してください。
